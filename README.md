# Marinara Desktop for Windows 11

마리나라를 Windows 11처럼 바꿔 주는 확장이에요. 저장 데이터는 Mac 버전(mallang-mac)과 호환돼요.

마리나라를 Windows 11 데스크톱처럼 바꿔 주는 확장이에요. 켜는 순간 다른 앱을 연 것처럼 보이게 하는 게 목표예요. 컴퓨터에서는 데스크톱처럼, 휴대폰과 태블릿에서는 홈 화면처럼 보여요.

## 컴퓨터에서

- **대화 목록 = 메신저처럼**: 같은 사람이 연달아 보낸 말풍선은 붙고(맞닿는 모서리가 작아져요), 말하는 사람이 바뀌면 사이가 벌어져요. 날짜 구분선은 작은 알약이 되어 그 날짜를 보는 동안 위에 붙어 있어요. "입력 중" 표시는 회색 말풍선 안에서 점 세 개가 통통 튀어요. 답장을 못 받으면 빨간 알림에 **다시 시도** 버튼이 붙고, 스와이프(2/5)는 작은 알약 하나로 정리돼요. 롤플에서 지금 써지는 글에는 왼쪽에 강조색 선이 생겨요.
- **움직임 = 스프링**: 시트, 빠른 설정, 토스트, 칩이 스프링처럼 감속하며 멈춰요(CSS linear()로 계산한 곡선, 지원하지 않는 브라우저는 기존 곡선). 칩·카드는 누를 때 살짝 들어가요. 설정 섹션을 바꾸면 내용이 부드럽게 바뀌어요(View Transitions). 동작 줄이기를 켜면 모두 꺼져요.
- **Vercel 인터페이스 가이드라인 점검**: 휴대폰에서 누르는 곳은 모두 44px 이상(작은 버튼은 보이지 않는 누름 영역을 넓혔어요), 두 번 탭 확대 지연 없음, 시트·패널 안 스크롤이 뒤 화면으로 번지지 않음, 바뀌는 숫자는 폭 고정, 제목 줄바꿈 균형, 어두운 테마에서 스크롤바·선택 상자도 어둡게, 토스트에 닫기 버튼(밀기 말고도 닫을 수 있게), 검색 안내 문구 끝에 "…".
- **아이콘 스타일 6종 추가**: 꾸미기 → 모양 → 아이콘 스타일. 색만 바꾼 게 아니라 그림이 두 벌이에요.
  - **선 아이콘**(가는 선 그림): **라인**(회색 타일), **외곽선**(빈 타일에 앱 색 테두리), **선만 (배경 없음)**.
  - **솔리드 아이콘**(새로 그린 꽉 찬 그림, 구멍이 뚫린 모양): **솔리드 투톤**(보조 부분을 옅게, 앱 색 타일), **솔리드 흑백**(글자색 타일), **솔리드 (배경 없음)**(앱 색 그림만). 구멍은 진짜로 비어 있어서 배경화면 위에서도 뒤가 보여요.
  - 아이콘 편집에서 바꾼 앱 색을 따라가고, 어두운 테마에서는 밝은 쪽 색을 써요. 바탕화면·작업 표시줄의 배경 없는 아이콘엔 옅은 그림자가 깔려요. 내 이미지를 넣은 아이콘은 바뀌지 않아요.
- **입력창**(대화·롤플·게임 전부): 카드가 아주 살짝 비쳐요(92% 불투명 + 흐림). 뒤 채팅은 흐릿하게만 보이고 쓰는 글을 방해하지 않아요. 카드 아래 비어 있던 띠(그 사이로 메시지가 지나가 보이던 곳)를 막았어요. 컴퓨터·태블릿은 그 띠를 바탕색으로 채우고, 휴대폰은 카드가 화면 아래 끝까지 내려가요(버튼은 홈 표시줄 위에 그대로). 투명 효과 끄기·차분하게 설정에선 흐림이 빠져요.
- **키보드로 다루기**: 칩·둘 중 고르기 버튼·설정 섹션 목록·채팅 설정 바로가기 칩은 Tab 한 번으로 들어가서 화살표·Home·End로 옮겨 다녀요(고르기 버튼은 옮기면 바로 선택). 빠른 설정을 키보드로 열면 안으로 들어가고, 닫으면 연 버튼으로 돌아와요. `?` 도움말은 화면 끝에 닿으면 안쪽으로 비켜서고 아래 자리가 없으면 위로 떠요. 모든 버튼에 같은 강조색 초점 테두리가 생겨요.
- **디자인 토큰**: 새로 바꾼 화면(설정, 빠른 설정, 시트, 토스트)은 같은 모서리 둥글기(10·14·20·24px), 같은 움직임 곡선, 같은 그림자 3단계를 써요. 성공·오류 색은 밝은·어두운 테마 모두에서 글자 대비 기준(WCAG AA)을 넘는 색이에요.
- **알림 = 쌓이는 토스트**: 저장·복사·오류 같은 알림이 카드로 쌓여요. 새 알림이 맨 앞, 이전 것들은 뒤로 살짝 겹쳐 보이고, 마우스를 올리면 펼쳐지면서 사라지는 시간이 멈춰요. 옆으로 밀면 닫혀요. 성공은 초록 체크, 오류는 빨간 느낌표가 붙고 오류는 조금 더 오래 떠 있어요. 컴퓨터는 오른쪽 아래, 휴대폰은 위쪽 가운데예요. 이미지가 너무 크거나 저장 공간이 찼을 때 뜨던 브라우저 경고창도 이 알림으로 바뀌었어요.
- **시트 끌어내려 닫기**(휴대폰): 채팅 설정, 오른쪽 패널, 빠른 설정, 팝업 창의 손잡이나 제목 줄을 아래로 끌면 따라 내려오고, 3분의 1 넘게 끌거나 빠르게 튕기면 닫혀요. 조금만 끌면 제자리로 돌아가요. 위로 끌면 살짝 늘어나요. 안쪽 스크롤, 버튼, 입력칸은 그대로 동작해요.
- **설정 새 단장**: 설정 창 맨 위에 **설정 검색**이 생겼어요. 항목 이름을 치면 어느 섹션에 있는지와 함께 나오고, 누르면 그 항목으로 바로 가서 잠깐 반짝여요. 처음 화면은 **전체**예요. "앱 전체 · 채팅 · 정보" 카드마다 섹션 이름과 그 안에 든 것(회색 한 줄)이 보여요. 창을 640px보다 좁히면 왼쪽 목록이 아이콘 탭 줄로 바뀌어요. 고를 게 5개 이하인 항목은 드롭다운 대신 **칩**(4 · 6 · [5])으로 바로 눌러 골라요. 긴 안내 문구는 제목 옆 **?** 를 누르면 보여요.
- **빠른 설정 = 관리실**: 위에 제목과 설정·닫기 버튼, 그 아래 **상태 카드**(창: 열린 창 수 · 확장: 보관함 개수 · 테마: 강조색)가 있어요. 카드를 누르면 그 설정으로 가요. **빠른 스위치**에 켜고 끄는 설정이 6개 보이고, "전체 N개"를 누르면 전부 나와요. 집중 모드·위젯 편집·창 정렬은 알약 버튼으로 남았어요. 휴대폰에서는 손잡이가 달린 아래쪽 시트로 올라와요.
- **홈 = 바탕화면 위젯 보드**: 홈에서는 창이 사라지고 배경화면 위에 위젯만 남아요.
  - 왼쪽: 마리나라 홈 위젯(최근 채팅, 교수님 등)
  - **API 가계부·크레딧 = 바탕화면 위젯**: 크레딧 확장의 카드 판 대신, 그 데이터를 그대로 읽어 오는 위젯으로 바뀌어요(처음 한 번 자동으로 바뀌고, 원래 카드 판은 꺼져요). 다른 위젯처럼 아무 데나 옮기고 크기를 바꿔요. 홈에 들어올 때마다 값이 갱신되고, 채팅 중에도 마지막 값이 보여요.
    - **API 가계부**: 작게(이번 달 합계·증감), 보통(+ 오늘·월말 예상), 크게(+ 일별 지출 열지도, 많이 쓴 곳 순위, 요청 수·사이트 집계).
    - **보기 방식 5가지**: 위젯 추가에서 바로 고르거나, 위젯의 i → 보기 방식에서 바꿔요. 같은 가계부를 여러 개 놓고 각각 다른 방식으로 볼 수 있어요.
      - 요약: 위 설명 그대로
      - 달력: 일별 지출 열지도를 위젯 크기만큼 크게(크게는 적게~많이 범례)
      - 일별 막대: 날마다 쓴 금액을 막대로, 오늘은 테두리
      - 많이 쓴 곳: 비율 고리 + 순위
      - 숫자 모음: 이번 달·오늘·월말 예상·요청 수를 칸마다 크게
    - **크레딧**: 카드 하나를 위젯 하나로. 위젯의 i 에서 어떤 크레딧을 보여 줄지 골라요. 이름, 요금제, 잔액이 크게, 사용량 막대가 아래 끝에.
    - **API 크레딧**: 모든 크레딧을 한 목록으로.
    - 크레딧 확장이 값을 못 받아 와서 `NULL`·`undefined`·`NaN`이 들어 있으면 그 글자는 빼고, 금액이 비면 — 로 보여요. 크레딧 확장이 직접 그린 카드(홈의 카드 판)에서도 글자가 null뿐인 칸은 숨겨요.
    - 원래 카드 판(달 넘기기, 설정, 파이 차트 전환)이 필요하면 **홈 구성 → 크레딧 카드 보이기**를 켜요.
  - 오른쪽: **새 채팅** 위젯(대화·롤플레이·게임 앱 아이콘)과 시계, 캘린더, 디데이. 새 채팅도 다른 위젯처럼 옮기고, 크기를 바꾸고, 지울 수 있어요.
  - 가운데 보드는 오른쪽 위젯 줄과 겹치지 않게 그만큼 비켜서 놓여요.
- **채팅 창을 열어도 위젯이 남아요**: 화면이 넓으면 채팅 창이 오른쪽 위젯 줄을 비워 두고 열려요. 창 크기를 바꾸면 위젯 줄도 오른쪽 끝을 따라가요.
  - **확장** 위젯: 모아 둔 버튼(기억 서재, 페르소나 제작실 같은 것)을 앱 아이콘처럼 보여 줘요. 누르면 그 확장이 열려요. 버튼은 전부 들어 있고, 보통 크기는 옆으로, 작게·크게는 아래로 끌거나(마우스) 밀어서(터치) 또는 휠로 넘겨 봐요. 더 있는 쪽 끝은 흐려져요.
  - 모든 위젯이 같은 디자인을 써요. 유리 카드, 22px 둥근 모서리, 작은 회색 제목, 굵은 숫자, 강조색 막대가 똑같아요. 버튼은 마우스를 올렸을 때만 보여요.
- **도움말 문구 → ⓘ**: "캐릭터를 폴더로 드래그 앤 드롭하고…" 같은 긴 안내는 새 폴더 버튼 끝의 ⓘ 아이콘으로 줄어들어요. 마우스를 올리거나 누르면 보여요.
- **작업 표시줄** (아래쪽): 왼쪽에 로고 메뉴, 앞에 있는 창 이름, 보기·윈도우·작업 표시줄·도움말 메뉴가 있고, 가운데에 고정 앱, 오른쪽에 트레이·검색·빠른 설정·시계가 있어요.
- **작업 표시줄 아이콘**:
  - 평소엔 숨어 있다가 마우스를 화면 아래 끝에 가져가면 올라와요.
  - 열린 앱 아래에는 짧은 막대, 지금 보고 있는 앱에는 긴 강조색 막대가 생겨요.
  - 가운데에 **최근 채팅 3개**가 캐릭터 얼굴로 나와요. 누르면 바로 열려요.
  - 아이콘을 오른쪽 클릭하면 열기·닫기·아이콘 편집 메뉴가 나와요.
- **창**: 채팅 목록, 채팅/편집 화면, 오른쪽 패널이 각각 떠 있는 창이에요.
  - 오른쪽 위 닫기 버튼을 누르면 홈으로 가요. 최소화 버튼은 작업 표시줄로 내리고, 최대화 버튼은 확대/축소예요.
  - 제목 표시줄을 끌면 옮겨지고, 가장자리를 끌면 크기가 바뀌어요. 더블클릭하면 확대돼요.
  - 화면 맨 위로 끌면 꽉 채워지고, 왼쪽·오른쪽 끝으로 끌면 반쪽에 붙어요.
  - 설정은 넓은 두 칸 창(왼쪽 카테고리, 오른쪽 내용)으로 열려요. 창 크기는 패널마다 따로 기억해요.
  - 창을 끌어도 마리나라의 "끌어내려서 검색 / 마리 교수님께 묻기"가 뜨지 않아요.
- **앱 에이전트**(오토메 하스, 스토리 라이터 같은 홈 탭 앱): 위쪽 "Marinara Engine" 로고와 탭 줄 없이 창 하나로 열려요. 닫기 버튼을 누르면 닫히고 바탕화면으로 돌아가요. 제목 줄은 그 앱의 배경색을 따라가서, 어두운 앱이면 어둡게 바뀌어요.
- **채팅 목록 = 메신저 앱**: 동그란 42px 사진, 굵은 이름, 회색 상태 글, 오른쪽 위 시간. 열린 채팅은 강조색으로 채워지고, 삭제 버튼은 마우스를 올렸을 때만 보여요. 컴퓨터에서는 모드 탭(대화·롤플·게임)을 숨기고 작업 표시줄의 앱 세 개로 나눠요. 채팅 사이엔 사진 뒤부터 얇은 구분선. 휴대폰·태블릿에선 사진 48px, 이름 16px, 줄 높이 70px로 더 커요.
- **앱마다 다른 채팅 목록**: 대화·롤플·게임이 앱 세 개처럼 각자 모양이 달라요. 목록 바탕은 테마 색과 **테마의 꾸밈(무늬·그림)**을 그대로 쓰고, 앱마다 색만 살짝 바꿔요.
  - **대화 = 메신저**: 동그란 50px 사진, 굵은 이름과 오른쪽 위 시간, 그 아래 **마지막 메시지 두 줄**(내가 보낸 건 "나:", 그림은 🖼). 마리나라 목록엔 미리보기가 없어서 화면에 보이는 채팅만 메시지 1개씩(두 개씩 동시에) 받아 와요. 다시 받는 건 그 채팅 시간이 "방금"이 됐을 때(새 메시지)뿐이고, 받은 미리보기는 이 브라우저에 남아서(최근 300개) 새로 고침해도 다시 받지 않아요.
  - 대화(메신저 앱): 위쪽 새 대화 버튼이 연필 모양, 열린 채팅은 강조색으로 채운 줄(휴대폰은 옅은 강조색). 창 제목은 마리나라 대화 머리글(사람·통화 버튼)이 맡아요.

Gemini 4 Neon 프리셋을 추가했어요(가격은 확인 필요). **원래 영수증 확장은 꺼 주세요**(둘 다 켜면 먼저 뜬 쪽 하나만 동작해요). 저장 공간이 달라서 원래 확장에 저장한 단가·환율은 옮겨지지 않아요.

- **책 종이 위 해가 까맣던 것**(2.23.2): 2.23.0에서 눈이 보이게 날씨 그림 전체를 어둡게 했더니, 해(햇빛 덩어리)까지 까만 얼룩처럼 보였어요. 이제는 어둡게 하지 않고, 눈송이 같은 입자에 잉크 색 테두리를 아주 얇게 둘러서 보이게 해요. 해는 원래처럼 옅은 노란 빛이에요.

- **편집기 창**(2.22.6): 채팅 중에 모델·캐릭터·프리셋 같은 편집기를 열면, 마리나라는 (컴퓨터 화면에서) 채팅을 내리고 그 자리에 편집기를 보여 줘요. 예전엔 채팅 목록이 그대로 붙어 있어서 채팅 창이 편집기로 바뀐 것처럼 보였어요. 이제 편집하는 동안엔 목록이 떨어져 창 뒤에 숨고, 창은 목록 없는 편집기 창이 돼요. 편집기를 닫으면(← 뒤로) 채팅이 돌아오고 목록도 다시 붙어요. 채팅과 편집기를 동시에 띄우는 건 마리나라가 채팅을 내려 버려서 할 수 없어요.

- **한 창짜리 메신저**(컴퓨터): 채팅 목록이 열려 있으면 대화 창 왼쪽에 붙어서 메신저처럼 한 창이 돼요. 목록은 대화 창 폭을 깎지 않고 왼쪽으로 덧붙어요(화면이 모자랄 때만 줄어요). 목록을 접어도 대화 창은 그 자리 그대로예요. 접힌 목록은 대화 창 뒤 왼쪽 끝에 숨어 있다가, 펼치면 그 뒤에서 왼쪽으로 미끄러져 나와요(멀리서 날아오지 않아요). 끌어서 화면 끝에 붙일 때도 놓은 자리에서 바로 붙어요. 창 제목 줄 가운데에 지금 채팅 이름이 보여요. 목록 제목도 "채팅" 대신 앱 이름(대화·롤플레이·게임)이에요. 함께 옮겨지고 크기가 바뀌고, 둘 사이 경계를 끌면 목록 폭(240~480px)이 바뀌어요. 창 오른쪽 위의 최소화·최대화·닫기 버튼은 목록 쪽 하나(창 전체를 닫기·최소화·최대화). 대화 창 제목 줄의 **사이드바 버튼**으로 목록을 접으면 대화가 창 전체를 쓰고, 다시 누르면 펼쳐져요. 기본은 꺼져 있어서 목록과 대화가 따로 떠요. 보기 메뉴 → "메신저 한 창"으로 켤 수 있어요. **태블릿(가로, 1000px 이상)**는 메신저 앱처럼 분할 화면이에요: 목록에서 채팅을 고르면 목록이 왼쪽(360px, 화면 높이 전체)에 붙은 채로 오른쪽에 대화가 열리고, 어둡게 가리지 않아요. 왼쪽 위 ▯ 버튼으로 목록을 접으면 대화가 화면 전체를 써요. 휴대폰은 한 화면씩 그대로예요.
- **시작 메뉴**: 모든 앱을 격자로 보여 줘요. 마리나라 홈 탭(교수님, Noodle, Slurp 같은 것)도 각각 앱으로 들어 있어요. 바로 타이핑해서 찾을 수 있어요. 앱을 오른쪽 클릭 → "새 폴더에 넣기" 또는 "'이름' 폴더에 넣기"로 **폴더**를 만들 수 있어요. 폴더를 누르면 안의 앱이 보이고(‹ 버튼으로 돌아가요), 폴더를 오른쪽 클릭하면 이름 바꾸기·삭제(앱은 그대로 남아요)가 나와요. 검색은 폴더 안 앱까지 찾아요.

### 앱마다 따로 열리는 창

대화, 롤플레이, 게임, 캐릭터·페르소나·로어북·프리셋·연결·에이전트·설정, 홈 탭의 앱(제작 도구 포함), 최근 채팅이 **각각 별도 창**으로 열려요. 여러 개를 나란히 띄워 놓고 스냅으로 배치할 수 있어요. 각 창은 그 안에 Marinara 화면이 하나씩 따로 들어 있는 구조라서, 창을 많이 열면 그만큼 메모리를 더 써요. 다시 불러오면(새로 고침) 열려 있던 창은 닫힌 상태로 시작해요. 작업 표시줄 메뉴의 "앱마다 따로 창 열기"를 끄면 예전처럼 한 창에서 바뀌어요.

마리나라 서버가 자기 화면을 창(iframe) 안에 띄우지 못하게 막아 두었으면(`X-Frame-Options: DENY` 또는 `frame-ancestors 'none'`, 이 경우 창에 "127.0.0.1에서 연결을 거부했습니다"가 떠요), 이 기능은 자동으로 꺼져요. 그때는 채팅 목록·대화·오른쪽 패널이 각각 끌고 크기를 바꿀 수 있는 창으로 열리고, "앱마다 따로 창 열기"는 회색으로 바뀌어요. 마리나라는 채팅과 패널을 한 번에 하나씩만 그려서, 이 모드에서는 대화 창 하나와 패널 창 하나를 나란히 쓸 수 있어요.

### 휴대폰·태블릿

- **모바일 패널 = 설정 시트**(휴대폰·태블릿): 채팅 설정, 오른쪽 패널(캐릭터·프리셋·설정 등), 편집 화면, 팝업 창이 같은 모양으로 바뀌어요. 회색 바탕에 흰 둥근 카드, 위에 손잡이, 굵은 큰 제목, 동그란 닫기 버튼이에요. 스위치는 더 크고(켜지면 강조색), 둘 중 고르기 버튼은 알약 트랙, 설정 분류·편집 탭은 옆으로 넘기는 알약 탭이에요. 휴대폰에서는 팝업 창도 아래에서 올라오는 시트예요.
  - **채팅 설정 바로가기**: 제목 아래에 섹션 칩 줄이 생겨요. 칩마다 섹션 이름과 상태(개수·꺼짐 같은 요약)가 보이고, 누르면 그 섹션이 열리면서 그 자리로 스크롤돼요. 열려 있는 섹션은 테두리로 표시돼요.

- **휴대폰**: 홈 화면이 라이브 타일로 된 시작 화면이에요(큰 타일 두 개, 나머지는 작은 타일·넓은 타일). 아래쪽 내비게이션 바에 시작(앱 목록)·검색·빠른 설정이 있고, 앱 목록은 세로 목록이에요. 앱 안에서는 아래 가운데의 작은 시작 버튼을 누르면 홈으로 돌아가요.
- **태블릿**: Windows 11 태블릿 모드처럼 홈 화면 아래에 작업 표시줄(시작·검색·앱, 오른쪽에 빠른 설정·시계)이 있어요. 시작 메뉴·빠른 설정·달력은 컴퓨터와 같은 패널로 열려요. 앱 안에서는 작업 표시줄이 내려가고 시작 버튼만 남아요.

### Windows 11 기능

- **스냅 레이아웃**: 창의 최대화 버튼에 마우스를 올리면 6가지 배치(반반, 2:1, 3분할, 반+사분할, 사분할, 1:2:1)가 떠요. 칸을 누르면 그 자리로 창이 붙어요.
- **화면 모서리 스냅**: 창을 화면 위쪽으로 끌면 최대화, 왼쪽·오른쪽 가장자리는 반쪽, 모서리는 4분의 1로 붙어요.
- **Ctrl + Alt + 방향키**: 선택한 창을 왼쪽/오른쪽 반쪽, 위(최대화·위쪽 사분할), 아래(복원·아래쪽 사분할·최소화)로 옮겨요. Windows의 Win + 방향키와 같아요.
- **최대화한 창**은 모서리가 각지게 바뀌어요.
- **작업 표시줄**: 실행 중인 앱 아래에 짧은 막대, 지금 보고 있는 앱에는 길고 강조색인 막대가 보여요. 맨 오른쪽 끝의 얇은 칸을 누르면 바탕 화면을 보여줘요.
- **시계를 누르면 달력**이 열려요. 달을 넘겨 볼 수 있고, 아래의 집중 세션 버튼으로 집중 모드를 켜요.
- **빠른 설정**: 토글 타일(테마 동기화, 자동 숨기기, 유리 효과, 집중 세션, 위젯 편집, 창 정리), 강조색, 배경화면, 그리고 아래쪽에 설정·전원(클래식 레이아웃) 버튼이 있어요.
- **시작 메뉴**: 고정된 앱(세 줄씩 넘겨 보기)과 **추천**(최근 채팅 6개)이 있어요.

## 알림 배지

앱 아이콘 오른쪽 위에 빨간 숫자가 떠요(작업 표시줄, 시작 메뉴, 휴대폰·태블릿 홈, 바탕화면 아이콘, 새 채팅 위젯).

- **채팅**: 대화·롤플·게임에서 읽지 않은 채팅 수를 합쳐서. 새 채팅 위젯의 대화·롤플·게임 버튼에는 각각 따로.
  - 컴퓨터: 마리나라 채팅 목록의 빨간 숫자를 그대로 읽어요.
  - 휴대폰·태블릿: 채팅 목록이 닫혀 있으면 45초마다 채팅 목록 API(`/api/chats`)를 확인해요. 이때는 캐릭터가 먼저 보낸 메시지(자율 메시지)만 세요.
- **홈 탭 앱**(Noodle 등): 마리나라 홈 탭에 뜬 배지를 그대로 옮겨요. 홈을 연 적이 있어야 알 수 있고, 마지막으로 본 값을 유지해요.

## 꾸미기 창 (모든 설정)

작업 표시줄 로고 → **꾸미기…**, 시작 메뉴나 홈 화면의 **꾸미기** 앱, 빠른 설정의 **꾸미기 설정 열기**로 열어요. 왼쪽 카테고리에서 골라요.

- **모양**
  - 테마 라이브러리와 색상 동기화
  - 강조 색상(맨 앞 무지개 원이 **테마**)
  - 아이콘 스타일·모양, 아이콘 편집
  - **마우스 포인터**: 시스템 기본 / 검은 화살표 / 흰 화살표 / 강조색 화살표 / 동그라미 / 내 이미지, 크기(보통·크게·아주 크게). 검은·흰 화살표는 링크와 버튼 위에서 손가락 모양으로 바뀌어요. 내 이미지는 64px 이하 PNG로 줄여 저장하고, 왼쪽 위 끝이 클릭하는 점이에요. 창 가장자리 크기 조절·끌기 모양과 입력칸의 I자 모양은 그대로예요.
- **배경화면**: 기본 배경화면, 이미지 업로드, 이미지 주소. **앱 테마** 배경화면은 적용된 테마 색으로 만들어져요.
- **홈 구성**
  - 위젯·아이콘 배치(그리드 / 자유)
  - 마리나라 홈 위치, 크레딧 카드·마리나라 위젯 보이기, 자동 정렬
  - 위젯 편집, 앱·북마크 추가
- **채팅 꾸미기**: 아래 설명 참고
- **작업 표시줄**: 크기, 자동 숨기기, 최근 채팅. 앱을 오른쪽 클릭하면 "작업 표시줄에 고정/제거"(시작 메뉴·데스크톱 아이콘에서도 돼요), 작업 표시줄 아이콘은 "왼쪽/오른쪽으로 이동"으로 순서를 바꿔요. 채팅 목록의 채팅(대화·롤플레이·게임)이나 시작 메뉴의 추천 채팅도 오른쪽 클릭 → "작업 표시줄에 고정"으로 하나씩 고정할 수 있어요. 작업 표시줄 메뉴의 "작업 표시줄 초기화"로 처음 상태로 돌아가요.
- **YouTube**: API 키, 플레이어(개인정보 보호 / 내 계정으로)
- **성능**: 진짜 유리 효과, 투명 효과 줄이기, 움직임 줄이기, 시작 화면
- **정보**: 단축키, 클래식 레이아웃, 창 배치 초기화

빠른 설정(작업 표시줄 오른쪽)은 자주 쓰는 것만 모았어요: 강조 색상, 배경화면, 테마 동기화, 작업 표시줄 자동 숨기기, 유리 효과, 배치 방식, 위젯 편집.

## 테마 라이브러리 동기화

마리나라 **설정 → 모양 → 테마 라이브러리**에서 적용한 테마를 따라가요. 기본으로 켜져 있어요.

- 강조색: 테마의 강조색(`--primary`, `--marinara-app-accent-solid`)
- 창 색: 테마의 배경·카드·사이드바·글자색
- 글꼴: 테마가 전체 글꼴을 정하면 그 글꼴
- 꾸밈 요소: 테마가 앱 배경에 그림이나 그라데이션을 넣었다면 **앱 테마** 배경화면이 그걸 써요. 없으면 테마 색으로 배경화면을 만들어요.
- 테마를 바꾸거나 밝게/어둡게를 바꾸면 바로 반영돼요. 끄면 원래 Marinara Desktop 색으로 돌아와요.

## 채팅 꾸미기

꾸미기 창 → **채팅 꾸미기**. 위쪽 미리보기와 뒤에 열린 실제 채팅이 같이 바뀌어요.

- **대화**
  - 프리셋: 기본 / 노랑 말풍선 / 초록 말풍선 / 다크 / 파스텔
  - 글꼴(시스템·명조·둥근·손글씨·고정폭·테마 글꼴·직접 입력), 글자 크기, 모서리, 글 폭
  - 내 말풍선 색·글자색, 상대 말풍선 색·글자색
  - 채팅 배경(기본 / 색 / 배경화면 비치게 / 이미지)
  - 프로필 사진(동그라미 / 둥근 사각 / 숨기기), 이름 보이기
- **롤플**
  - 프리셋: 세피아 / 라이트 / 다크 / 양피지 / 타자기
  - 롤플 화면(리더 세피아·라이트 / 리더 다크 / 깔끔하게)
  - 글꼴(기본 프리텐다드), 글자 크기, 줄 간격, 글 폭, 종이 색, 글자 색. 마리나라에 올린 글꼴(설정의 글꼴 업로드)은 마리나라가 시작 직후 늦게 등록해도 자동으로 다시 적용돼요.
  - 읽기 화면: 양쪽 정렬, 행동(* *) 기울이기, 메시지 버튼은 가리킬 때만
  - **좌우 여백**(좁은 창·휴대폰, 0~48px, 기본 14px): 글과 입력창 양옆 여백을 조절해요. 테마가 글 폭을 고정해도 적용돼요. 휴대폰에서 입력창은 여백 없이 화면 양 끝까지 넓게, 위쪽 모서리만 둥글게 바닥에 붙어요.
  - **줄바꿈**: 글자 단위(기본, 줄 끝까지 채움) / 단어 단위(한국어 단어를 자르지 않음. 대신 일본어·중국어는 마침표 같은 문장부호에서만 줄이 바뀌어요)
  - **대사·서술·행동 색 구분**(기본 켜짐): 대사(" ")가 가장 진하고, 서술은 조금 연하고, 행동(* *)은 더 연해요. 굵기는 그대로예요. 세 색을 직접 고를 수도 있어요.
- **기본 디자인으로** 버튼으로 언제든 되돌려요.

## 작은 앱

작업 표시줄, 데스크톱 아이콘, 시작 메뉴, 바탕화면 오른쪽 클릭으로 열어요. 마리나라 창과 똑같이 끌고, 크기를 바꾸고, 최소화할 수 있어요. 열어 둔 창은 새로 고침해도 그대로 다시 열려요.

- **메모장**: 메모 여러 개를 만들고 지울 수 있어요. 쓰는 대로 확장 저장 공간에 저장돼요.
- **YouTube**(2.22): YouTube처럼 둘러보는 앱이에요. 최소화해도 소리는 계속 나요. 📌(항상 위에)를 누르면 다른 창 위에 계속 떠 있어요.
  - youtube.com 화면 자체는 YouTube가 다른 창 안에 띄우는 걸 막아 두었어요(`X-Frame-Options: SAMEORIGIN`, m.youtube.com도 같아요). 그래서 창 안에 그대로 띄울 수는 없고, **YouTube Data API 키**로 같은 화면을 이 창에서 그려요.
    - **홈**: 인기 동영상을 카테고리 칩(인기·음악·게임·엔터테인먼트·영화·애니·스포츠·뉴스·과학·기술)으로. 썸네일·길이·실시간 표시, 제목 두 줄, 채널, 조회수·올린 때.
    - **검색**: 위 칸에 검색어. 링크를 넣으면 바로 그 영상.
    - **영상 화면**: 플레이어, 제목, 채널(사진·구독자 수, 누르면 채널로), 조회수·날짜·설명(더보기), 옆에 "이 채널의 다른 영상"(창이 좁으면 아래).
    - **채널**: 채널 사진·이름·구독자 수와 최근 동영상.
    - ◀ 뒤로, ⌂ 홈. 같은 요청은 10분 동안 다시 묻지 않아요(할당량 절약: 검색 1번 100, 나머지 1번 1).
  - 키가 없으면 안내와 **API 키 넣기** 버튼이 떠요. 링크를 붙여 넣으면 키 없이도 재생돼요.
  - ⚙ **API 키**는 입력하는 대로 저장돼요(전엔 칸을 벗어나야 저장돼서, 붙여 넣고 바로 닫으면 저장되지 않았어요).
  - ⚙ **플레이어**: 개인정보 보호(youtube-nocookie) / **내 계정으로**(youtube.com 플레이어). **YouTube 로그인** 버튼으로 로그인 창을 열 수 있어요. 브라우저가 다른 사이트 쿠키를 막으면 창 안 플레이어에서는 로그인 상태가 안 보일 수 있어요.
- **인터넷**: 주소나 검색어를 넣어요. ◀ 로 뒤로 가요.
  - 모든 사이트를 먼저 **iframe**(창 안)으로 열어 봐요. YouTube 주소와 마리나라 페이지는 바로 열려요.
  - 다른 사이트는 지금 마리나라 서버의 보안 설정(CSP `frame-src`, 서버 코드에 고정)이 막아요. 브라우저가 막았다고 알려 주면 바로 아래 방법으로 바뀌어요. 마리나라가 나중에 그 사이트를 허용하면 그대로 창 안에서 열려요.
  - **리더로 보기**: 주소를 외부 서비스(r.jina.ai)에 보내 글·링크·이미지만 받아서 창 안에 보여 줘요. 사이트별로 기억해요(도구 막대의 문서 아이콘으로 끄고 켜요). 주소가 그 서비스로 간다는 점을 알아 두세요.
    - 디시인사이드는 첫 화면(www.dcinside.com)은 리더로 보이지만, 갤러리 글·목록(gall.dcinside.com)은 사이트가 리더 서비스를 막아서 내용이 오지 않아요. 그럴 땐 **새 창에서 열기**를 눌러요. 디시 이미지 서버도 다른 곳에서 불러오는 걸 막아서 리더에서는 이미지가 빠져요.
  - **창에 맞춤**(2.22): 디시처럼 넓게 만든 사이트는 창보다 넓어서 크게·잘려 보였어요. 이제 1280px 폭으로 그린 뒤 창 폭에 맞게 줄여서 한눈에 보여요. 도구 막대의 **%** 버튼에서 창에 맞춤 / 50~125%를 고를 수 있고, 사이트마다 기억해요. 바탕이 투명한 사이트 뒤로 검은색(영상용 바탕)이 비쳐서 이상하게 보이던 것도 흰 바탕으로 고쳤어요.
    - 디시 모바일(m.dcinside.com)은 사이트가 컴퓨터 브라우저를 PC 화면으로 보내서 창 안에선 쓸 수 없어요.
  - **새 창에서 열기**: 작은 브라우저 창을 옆에 띄워요.
  - ★를 누르면 그 주소가 북마크가 돼요.

## 북마크

- 인터넷 앱의 ★, 바탕화면 오른쪽 클릭 → **북마크 추가**, 빠른 설정 → 홈 구성에서 추가해요.
- 북마크는 데스크톱(휴대폰은 홈 화면)에 아이콘으로 생겨요. 사이트 아이콘(favicon)을 불러오고, 없으면 첫 글자로 보여 줘요.
- 누르면 YouTube 주소는 YouTube 앱, 나머지는 인터넷 앱에서 열려요.
- 오른쪽 클릭으로 이름 바꾸기, 새 창에서 열기, 삭제, 아이콘 편집을 할 수 있어요.

## 홈 화면 꾸미기

- **데스크톱 아이콘**: 앱이나 북마크를 바탕화면 아무 데나 놓고 끌어서 옮겨요. 한 번 누르면 열려요. 오른쪽 클릭이나 **앱·북마크 추가**로 아이콘을 더하고, 편집 모드의 − 로 빼요.
- **위젯**: 편집 모드에서 끌어서 옮기고, 크기와 스타일을 바꾸고, 더하거나 빼요.
- **배치 방식**:
  - **그리드**(기본): 위젯은 160px 칸(20px 간격)에, 아이콘은 아이콘 칸에 딱 맞춰 놓여요. 이미 있는 자리에 놓으면 가장 가까운 빈칸으로 가요. 편집 모드에서는 칸 위치가 점으로 보여요.
  - **자유**: 놓은 자리에 그대로 둬요(8px 단위).
  - 어느 방식이든 위젯끼리는 겹치지 않아요. 다른 위젯 위에 놓거나, 창 크기가 바뀌어 겹치게 되면 가장 가까운 빈자리로 비켜요.
  - 직접 끌어서 옮긴 적 없는 위젯은 지금 창 크기에 맞춰 오른쪽 줄에 차곡차곡 다시 쌓여요. 끌어서 놓은 위젯만 그 자리를 기억해요. **위젯 자동 정렬**을 누르면 모두 다시 쌓여요.
  - 홈 보드(최근 채팅·크레딧 카드)는 위젯 줄 20px 앞에서 끝나요. 크레딧 카드 자리가 380px보다 좁아지면 카드는 최근 채팅 아래로 내려가요.
  - 최근 채팅 카드의 캐릭터 사진은 오른쪽 위 작은 동그라미로 바뀌어서 이름과 미리보기를 가리지 않아요.
- **홈 구성** (편집 모드 아래 막대, 바탕화면 오른쪽 클릭, 빠른 설정):
  - 마리나라 홈 블록 위치: 왼쪽 / 가운데 / 숨기기
  - API 크레딧 카드 보이기·숨기기, 마리나라 홈 위젯 보이기·숨기기
  - 아이콘 자동 정렬, 위젯 자동 정렬
- **휴대폰 홈 화면**: 빈 곳을 길게 누르면 편집 모드가 돼요. 아이콘마다 − (홈에서 빼기)와 ◀ ▶ (순서 바꾸기)가 나와요. 뺀 앱은 **앱·북마크 추가**에서 다시 넣어요.

## 휴대폰·태블릿에서

- **채팅 목록 패널 새 디자인**(휴대폰·태블릿): 큰 제목이 지금 앱 이름(대화·롤플레이·게임), 그 옆에 작은 동그라미 버튼(가져오기·선택·**새 채팅**(강조색)·닫기). 모드 전환은 얇은 세그먼트, 검색은 둥근 회색 칸 하나(정렬은 작은 알약, 전체 검색은 둥근 버튼), "새 폴더"는 작은 글자 버튼. 체크무늬 대신 깨끗한 단색 배경, 열린 채팅은 옅은 강조색. 사진은 마리나라의 28px 사진 상자를 통째로 키워서(단독·여러 명·모드 아이콘 모두) 대화는 동그라미, 롤플은 책 표지, 게임은 앱 아이콘 모양. 목록 안의 대화·롤플·게임 전환은 없애고(앱이 따로라서), 앱은 메뉴 시트나 홈 화면에서 바꿔요.
- **휴대폰 전용 모양**:
  - 대화(콘보) 입력창도 롤플처럼 화면 양 끝까지 넓게, 위쪽 모서리만 둥글게 바닥에 붙어요(아래는 아래 가운데 시작 버튼 자리만큼 여백).
  - 입력창 아랫줄은 한 줄: 동그라미 버튼 36px, 모델 알약은 남는 폭만큼만. 꺼내 둔 입력 버튼(“” ✱ …)은 입력창 왼쪽 위.
  - 입력창 **+ 메뉴**와 **문구 보관함**, **확장**, **⋯ 메뉴**는 아래에서 올라오는 시트(손잡이 막대, 뒤는 어둡게, 바깥을 누르면 닫힘).
  - **모델 선택**도 화면 폭 전체의 아래 시트.
  - **편집 화면**(좁은 화면): 섹션이 드롭다운 대신 옆으로 넘기는 칩 줄(지금 섹션은 강조색), 여백을 줄였어요.
  - 알림 토스트는 입력창과 겹치지 않게 위쪽에. 입력창 버튼은 36px로 조금 작고, 모델 알약은 화면 폭의 30%까지.
- **위쪽 헤더 없음**(컴퓨터처럼): 마리나라의 위쪽 막대(홈·채팅·패널 버튼 줄)를 없애고, 그 자리는 앱 화면이 써요. 대신:
  - **롤플 에이전트 줄**(2.22.3): 휴대폰 롤플 채팅 맨 위의 에이전트 버튼 줄(Relationship Tracker 같은 것)은 마리나라 화면 배치에 붙어 있어서 끌어서 옮길 수 없어요. 그 줄이 캡슐 오른쪽에서 시작하게 비워 두어서 첫 버튼이 가려지지 않아요.
  - **관계 트래커 같은 마리나라 버튼을 가리지 않아요**(2.22.2): 캡슐은 그 자리에 떠 있는 작은 버튼(다른 확장 버튼, 그리고 이제 마리나라 자체의 트래커·채팅 설정 버튼도) 바로 아래로 비켜 앉아요. 화면을 덮는 창이나 시트는 버튼으로 치지 않고, 화면 위쪽 35% 아래로는 내려가지 않아요.
  - **왼쪽 위 유리 캡슐**(앱·채팅 안에서, 2.22.1부터 버튼 두 개가 아니라 아이콘 두 개가 든 캡슐 하나라서 서로 겹칠 수 없어요): ▯ 채팅 목록 접기/펼치기, ⋯ **메뉴 시트**(대화·롤플·게임 앱, 홈·캐릭터·페르소나·로어북·프리셋·연결·에이전트·설정·확장·꾸미기가 앱 아이콘으로). 그 자리에 다른 확장이 띄운 버튼(관계 트래커 등)이 있으면 버튼 두 개가 그 바로 아래로 비켜 앉아서 가리지 않아요.
  - 홈은 아래 가운데 시작 버튼. 태블릿 분할 화면에선 버튼이 목록 오른쪽에 붙어요. 휴대폰에서 목록이 화면을 덮을 땐 버튼이 숨어요.
  - 시트(설정·캐릭터 등)도 막대가 비운 만큼 위에서 시작해요. 맨 위 상태 막대 띠는 앱 배경색이에요.

- **홈 화면**: 휴대폰은 라이브 타일 시작 화면(큰 타일 두 개, 나머지는 작은·넓은 타일)이에요. 태블릿은 배경화면 위에 위젯과 앱 아이콘 격자가 놓이고, 앱 아이콘은 반투명 카드 위에 올라가요. 시작 메뉴·빠른 설정·달력은 컴퓨터와 같은 패널로 열려요. 아래에는 마리나라 인사말과 홈 카드가 이어져요.
- **내비게이션 바**(휴대폰): 홈 화면 아래에 시작(앱 목록)·검색·빠른 설정이 떠 있어요. 태블릿은 아래 전체 폭 작업 표시줄이 그 자리를 맡아요.
- **앱**: 큰 제목이 달린 휴대폰 앱처럼 열려요. 태블릿에서는 홈 화면 위에 모서리 8px인 창으로 뜨고, 뒤의 홈 화면(배경화면·위젯)은 그대로 남아요. 앱이 떠 있는 동안 내비게이션 바·작업 표시줄은 숨고, 아래 가운데 작은 시작 버튼만 남아요.
- **태블릿 가로 화면**: 가운데 1180px 폭에 위젯이 한 줄 6칸으로 넓게 퍼지고(큰 위젯은 두 줄 차지, 빈칸은 작은 위젯이 채움), 그 아래 앱 아이콘이 8칸 격자로 놓여요. 설정 같은 패널은 900px 폭 카드로 떠요.
- **태블릿에서 창을 열면**: 뒤쪽 홈 화면이 맨 위까지 전부 어둡게 가려져요. 채팅 목록 아래쪽 빈 띠가 없어지고, 앱 안에서는 상태 막대 자리가 위쪽 막대와 같은 색이에요. 아래 가운데 시작 버튼은 태블릿 자체 막대 위에 따로 놓여요.
- 캐릭터·페르소나 **아이콘 보기**는 컴퓨터 창에서만 써요. 태블릿에서는 마리나라의 원래 목록으로 보여요.
- **앱 에이전트**(오토메 하스, 스토리 라이터): 휴대폰·태블릿에서는 위쪽 탭 줄(홈 탭)이 그대로 보여요. 아래 가운데 시작 버튼, 마리나라의 홈 버튼, 홈 탭 어느 것으로도 홈 화면으로 돌아가요.
- **아래 가운데 시작 버튼**: 앱 안에서는 아래쪽 가운데 작은 시작 버튼을 누르거나 위로 쓸어 올리면 홈으로 돌아가요.
- **위젯 편집**: 홈 화면 빈 곳을 길게 누르면 위젯 편집 모드가 돼요.

## 채팅 화면

- **대화 모드 = 메신저 앱**:
  - 내 메시지는 오른쪽 강조색 말풍선이에요. 상대 답장은 문단마다 따로 회색 말풍선으로 나와요.
  - 작은 동그란 프로필, 가운데 정렬된 상단 이름 바, 조용한 날짜 구분선이 있어요.
  - 메시지 도구는 마우스를 올렸을 때만 보여요.
- **롤플 모드 = 읽기 화면**(유니챗 뷰어 참고):
  - 배경 이미지는 빠지고 세피아(또는 라이트·다크) 바탕에 프리텐다드 16px, 줄 간격 1.8로 읽혀요.
  - 글은 창 가운데 640px 폭에 놓여요. 마리나라의 채팅 위치가 왼쪽/오른쪽이어도 읽기 화면에서는 가운데예요.
  - 이름은 글 위의 조용한 라벨, 시간·모델명은 흐리게. 내 차례는 옅은 카드로 보여요.
  - 메시지 버튼은 작고 흐리게, 마우스를 올린 메시지(와 마지막 메시지)에만 보여요.
  - 입력창은 둥근 카드이고, 위쪽 글은 입력창 쪽으로 흐려져요. 창 제목 줄도 종이 색이에요.
  - 좁은 창(640px 아래)·휴대폰: 여백을 줄이고 글자를 조금 작게, 메시지 사이도 좁게 해요.
- 둘 다 꾸미기 창 → **채팅 꾸미기**에서 바꿀 수 있어요.

## 꾸미기

- **위젯**: 새 채팅, 시계, 아날로그 시계, 캘린더, 인사말, 디데이, 메모, 사진, API 가계부, 크레딧, API 크레딧, 확장 위젯이 있어요.
  - 크기: 작게 / 보통 / 크게
  - 스타일: 유리 / 밝게 / 어둡게 / 강조색 / 투명 (메모는 메모 색)
  - 디데이에는 제목과 날짜를 넣어요. 최애 생일이나 기념일을 세어 줘요.
  - 위젯 편집 모드에서는 위젯이 흔들려요. − 를 누르면 지우고, i 를 누르면 설정하고, 끌어서 옮겨요. 아래 막대의 "+ 위젯 추가"로 새 위젯을 넣어요.

  - 앱마다 이름, 두 가지 색, 직접 고른 이미지를 바꿀 수 있어요. 작업 표시줄 아이콘 오른쪽 클릭 → 아이콘 편집으로 바꾸거나, 빠른 설정 → 꾸미기 → 아이콘 편집에서 바꿔요.
  - 전체 아이콘 스타일: 그라데이션 / 유리 / 파스텔 / 틴트 / 다크
  - 아이콘 모양: 둥근 사각 / 동그라미 / 각진 사각
- **강조 색상** 9가지와 **배경화면** 6가지가 있어요. 내 이미지를 올리거나 https 이미지 주소를 넣을 수도 있어요.

## 성능

직접 재 보니 버벅임의 주범은 유리 효과(블러)였어요. 홈을 스크롤할 때 블러가 있으면 한 프레임이 42ms까지 걸렸고, 끄니 8~9ms로 줄었어요. 마리나라만 켰을 때(14ms)보다도 빨라요.

- **블러는 기본으로 꺼져 있어요.** 원하면 빠른 설정 → 성능 → **진짜 유리 효과**로 켤 수 있어요(느려질 수 있어요).
- **채팅 화면은 아예 지켜보지 않아요.** 답장이 스트리밍되면 화면이 1초에 수십 번 바뀌는데, 확장은 버튼·패널의 몇 가지 상태 변화만 보고 나머지는 0.7초마다 가볍게 확인해요. 탭이 안 보일 땐 그것도 쉬어요.
- **채팅 화면 CSS에서 무거운 선택자(`:has()`)를 뺐어요.** 스트리밍 중에도 스타일 재계산이 가벼워요.
- **닫힌 창은 아예 그리지 않아요**(`content-visibility`).
- 창을 끌 때는 화면을 다시 그리지 않는 방식(`translate`)으로 옮기고, 그동안은 블러도 꺼요.
- 이미지는 따로 저장해서, 창을 옮길 때마다 큰 데이터를 다시 보내지 않아요.
- 롤플 색 구분은 메시지를 고치지 않고(CSS Custom Highlight API) 1.2초마다 바뀐 메시지만 다시 봐요.
- **2.13.5 최적화**: 채팅 2,000개짜리 화면에서 가만히 있을 때 10초에 128ms → 81ms(스타일·배치 계산 0).
  - 읽지 않은 수는 채팅 줄마다 찾지 않고 빨간 숫자만 한 번에 찾아요. 작업 표시줄 최근 채팅은 목록 전체를 복사하지 않고 앞 3개만 봐요.
  - 한 번 확인하는 동안 같은 화면 요소는 한 번만 찾아요. 화면 바뀜 감시는 0.8초 → 1.5초, 원래 보관함 확장 확인은 5초마다.
- **2.6 최적화**: 가만히 있을 때 반복하던 일을 줄였어요.
  - 롤플 색 구분은 메시지 전체 대신 마지막 두 개만 읽어요(나머지는 10번에 한 번).
  - 홈 탭·크레딧 카드·앱 에이전트 색은 바뀌었을 때만 다시 읽어요.
  - 위쪽 막대 높이는 매번 재지 않고 크기가 바뀔 때만 받아요.
  - 시계 위젯은 분이 바뀔 때만 다시 그리고, 탭이 안 보이면 쉬어요.
  - 창 안 모든 요소에 걸리던 스크롤바 스타일(`*`)을 스크롤되는 요소로만 좁혔어요.
- 참고: 마리나라에 다른 확장이 많이 켜져 있으면(특히 `fetch`를 감싸는 확장들) 그쪽에서도 느려질 수 있어요.
- **2026-11-16 측정**: 가만히 있어도 0.5초마다 약 125ms씩 화면이 멈췄어요. 이 확장을 꺼도 똑같았고, 원인은 다른 두 확장의 조합이었어요.
  - 따옴표·별표 빠른 입력 칩(`.qp-chips-dock`)이 매 프레임 같은 class를 다시 써요.
  - "확장 보관함"이 그 변화를 보고 화면 전체를 다시 훑어요(요소마다 `getComputedStyle`·`getBoundingClientRect`).
  - 이 확장은 바탕화면 층에 `data-exd` 표시를 달아서 "확장 보관함"이 훑거나 숨기지 않게 했어요. 멈춤 자체를 없애려면 빠른 입력 확장이 class가 바뀔 때만 쓰게 고쳐야 해요.

## 설치

1. 서버의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`가 있어야 해요. (지금 설치본에는 이미 켜져 있어요.)
2. **설정 → 고급 → Danger Zone**에서 **Allow third-party extension imports**를 켜요.
3. **설정 → 애드온 → External Extensions**에서 **Import Extension Folder**를 누르고 이 `marinara-desktop` 폴더를 골라요. 폴더 대신 ZIP으로 묶어서 **Import Extension File**로 가져와도 돼요.
4. 가져온 확장을 열고 **Review and Run**을 눌러요. 화면 전체를 바꾸기 때문에 **Full page access** 권한을 요청해요. 확인 창에서 해시와 권한을 확인하고 승인해요.

코드를 고친 뒤 다시 가져오면 확장이 꺼지고 다시 승인해야 해요. 마리나라의 안전장치라서 정상이에요.

## 편의 기능

- **크레딧 위젯의 null**(2.20.2): 크레딧 카드·목록 위젯이 값을 새로 받을 때, 빈 칸(없는 줄·막대)이 "null" 글자로 찍히던 버그를 고쳤어요(위젯을 처음 그릴 땐 괜찮고 새로 고칠 때만 생겼어요).
- **모델 선택창 여백**(2.20.2): 칸 사이 여백을 줄이고, 출처 아이콘을 작게, "Edit order"를 제목 줄 오른쪽으로 올리고, 스크롤 막대를 얇게 했어요.
- **크레딧 카드의 null**: 크레딧 확장이 빈 칸 두 개를 이어 "nullnull"로 찍는 경우까지 숨겨요(전엔 null 하나만 숨겼어요). 카드 판이 나타나자마자 숨김이 시작돼요.
- **채팅 설정·트래커 버튼**(컴퓨터): 마리나라가 화면 좌표로 놓는 채팅 버튼(롤플의 채팅 설정, 트래커)이 대화 창 위치만큼 밀려서 화면 밖으로 나가 안 보이던 걸 고쳤어요. 이제 대화 창 오른쪽 위에 있고, 창을 옮기면 따라와요. 버튼이 여는 채팅 설정 창도 대화 창 안 제자리에 열려요.
- **최적화**(2.22.2): 가만히 있을 때 화면을 맞추는 일(동기화)이 0.7초마다 → 5초 동안 입력이 없으면 2.1초마다로, 한 번에 드는 시간도 약 3.8ms → 1.7ms로 줄었어요(롤플 채팅 10초 기준 약 54ms → 8ms). 채팅 제목·앱 확인은 채팅이 바뀌었을 때만, 늦게 등록되는 글꼴 확인은 처음 1분 뒤엔 5초마다, 왼쪽 위 버튼 자리 확인은 2초마다만 해요. 마리나라가 화면을 바꾸면(버튼·패널 열림) 지금처럼 바로 맞춰요.
- **입력창 글칸**: 테마가 모든 입력칸에 테두리 색을 줘도, 입력창 안의 글칸에는 네모 테두리가 생기지 않아요. 2.22.2부터는 글칸 자체에 직접(인라인, !important) 테두리·외곽선·그림자 없음을 넣어서 어떤 스타일시트도 이길 수 없어요.
- **휴대폰에서 위로 스크롤할 때**: 마리나라가 입력창을 "메시지…" 버튼으로 접는데, 이제 하얀 네모 상자로 바뀌지 않고 펼친 입력창과 같은 자리·색·둥근 위 모서리·높이를 그대로 지켜요(꺼내 둔 버튼은 접혔을 땐 숨어요).
- **입력창 = Claude 앱 입력바**: 모서리가 크게 둥근 카드에, 글은 윗줄 전체(16px), 아랫줄 왼쪽에 회색 동그라미 버튼(+, 번역 같은 도구)과 연결·페르소나, 오른쪽에 동그란 강조색 보내기 버튼(쓸 게 없을 땐 회색). **+ 메뉴**도 Claude 앱처럼 큰 둥근 카드에 아이콘이 달린 묶음 줄로 열리고, 아래 "입력창 위에 버튼으로"는 스위치예요(눌러도 메뉴가 닫히지 않아요). 보내기는 진한 동그라미에 ↑ 화살표(종이비행기 대신), 생성 중 멈춤 버튼도 같은 진한 동그라미예요. 대화(콘보) 입력창도 같아요: 모델 이름 알약·페르소나·도구가 회색 동그라미로, 보내기는 진한 동그라미. 휴대폰·태블릿에선 입력창이 아래 가운데 시작 버튼보다 위에 있어서 같이 눌리지 않아요(태블릿 시작 버튼 자리는 맨 아래 2px, 120×16).
- **모델 선택창**(2.20 새 디자인): 입력창의 연결 버튼은 지금 모델 이름이 적힌 회색 알약이에요. 누르면 컴퓨터에서는 화면 가운데(작업 표시줄을 가리지 않게)에 Windows 11 창처럼 떠요: 조용한 제목 줄, 지금 모델은 강조색을 옅게 깐 띠, 검색칸 하나, 왼쪽은 탐색 창 같은 출처 목록(즐겨찾기·계정, 고른 것만 옅은 강조색), 오른쪽은 한 줄짜리 모델 목록이에요. 모델 이름은 두 줄로 꺾이지 않고, 그 아래 작은 회색 글씨로 계정, 오른쪽에 가격은 작은 글씨, 지금 모델은 옅은 강조색 줄에 체크, 즐겨찾기는 노란 별. 설정 버튼과 비어 있는 별은 마우스를 올렸을 때만 보여요. 역할 배지(Agents 등)는 숨기고 경고(키 없음 등)는 그대로예요. 색은 테마를 따라요. 휴대폰은 아래에서 올라오는 시트에 같은 줄 모양이에요. 입력창엔 모델 알약과 페르소나 버튼만 있어요(휴대폰의 빠른 전환기 ^는 없앴어요).

- **확장**(예전 이름 "확장 보관함", 2.21부터 그냥 "확장"): 다른 확장이 화면에 띄우는 버튼을 한곳에 모아요.
  - **버튼을 모으는 쪽 고르기**: 확장 → 편집 맨 위에서 **내장** 또는 **확장 보관함 확장**을 골라요.
    - 내장(기본): 이 확장이 버튼을 모아요. "확장 보관함" 확장이 설치돼 켜져 있어도, 이 페이지에서는 그 확장이 스스로 정리하는 함수를 불러 재워요(버튼은 원래대로 돌려놓고 멈춰요). 마리나라 설정은 건드리지 않아서, 나중에 그쪽으로 바꾸면 새로 고침만 하면 돼요.
    - 확장 보관함 확장: 이쪽 엔진은 쉬고, 그 확장이 버튼을 숨겨요. 작업 표시줄의 확장 아이콘·휴대폰 시트·확장 위젯은 그 확장이 숨긴 버튼을 **그 확장에서 붙인 이름**으로 보여 주고 눌러 줘요. 이름·순서 같은 편집은 그 확장의 보관함 아이콘 → 보관함 편집에서 해요(확장 → 편집의 "확장 보관함 열기"). 그 확장이 꺼져 있으면 켜 달라는 안내가, 이 페이지에서 재웠던 상태면 새로 고침 버튼이 떠요.
  - **연동**: 어느 쪽을 써도 이름·순서·화면에 두기·뺀 버튼·새 버튼 저절로 담기 설정이 서로 맞춰져요. 두 쪽은 버튼을 다른 방식으로 기억해서, 같은 버튼은 **버튼 이름표**(aria-label 등)로 짝을 지어요.
    - 내장을 쓰는 동안 편집하면 1.5초 뒤 그 확장의 서버 저장소에도 같은 내용을 써요(그 확장이 아는 버튼만, 순서는 이쪽 순서대로).
    - 내장으로 바꿀 때, 그리고 페이지를 열 때 그 확장이 더 나중에 저장했으면 그 내용을 가져와요. 그 확장이 기억하는 이름은 아직 이쪽에 없는 버튼이 처음 담길 때도 쓰여요.
  - **최적화**(2.21): 위젯·목록은 페이지 전체를 찾지 않고 이 확장이 기억하는 버튼만 봐요(전엔 화면을 고칠 때마다 `[data-bgh-stored]` 전체 검색). "확장 보관함" 확장이 켜졌는지는 페이지 검색 대신 그 확장의 함수가 있는지만 봐요. 담긴 버튼은 크기·자식·class·style 변화를 직접 지켜보니, 전체 다시 확인은 4번에 1번 → 20번에 1번으로, 새 버튼 찾기는 8초 → 15초마다로 줄였어요. 확장 보관함 확장 쪽을 고르면 이쪽 엔진은 아무것도 하지 않아요. 내장을 고르면, 페이지 안의 모든 class·style 변화를 지켜보던 그 확장이 멈춰서 그만큼 가벼워져요.
  - 새로 뜬 버튼은 잠깐(약 1초) 떠 있으면 저절로 담기고, 제자리에서 투명하게 숨겨져요(옮기거나 지우지 않아요).
  - 컴퓨터: 작업 표시줄 오른쪽 상자 아이콘을 누르면 목록이 아래로 열려요.
  - 휴대폰·태블릿: 채팅·앱 안에서는 왼쪽 위 ⋯ 메뉴 → **확장**, 홈 화면에서는 **확장** 앱(시작 메뉴에도 있어요). 누르면 아래에서 시트가 올라오고, 담긴 버튼이 앱 아이콘 격자로 보여요. 어두운 바깥을 누르면 닫혀요.
  - 위젯으로도 놓을 수 있어요.
  - 이름을 누르면 손가락으로 누른 것처럼(포인터·마우스·클릭) 원래 버튼이 눌려요. 끌 수 있는 버튼(누를 때 포인터를 붙잡는 버튼)도 원래 확장처럼 잘 눌리고, 버튼이 shadow DOM 안에 있어도 안쪽 진짜 버튼을 눌러요. 버튼이 그 자리에서 펼쳐지면 펼쳐진 동안은 보이고, 접히면 다시 숨어요.
  - **편집**: 이름 바꾸기, 순서(↑↓), 화면에 두기, 빼기(아래 "뺀 버튼"에서 다시 넣기), 없어진 버튼 지우기, 자동 담기 켜고 끄기, **직접 담기**(누른 버튼을 담기, 마리나라 기본 버튼은 안 돼요), 보관함 끄기.
  - **이름**: 직접 붙인 이름 → 그 버튼을 띄운 확장의 이름(한글이면) → 버튼 설명 순으로 보여요. 확장 이름은 원래 확장처럼 찾아요: 켜진 확장 목록을 받아, 그 버튼을 꾸미는 확장 스타일시트, 버튼 설명과 같은 확장 이름, 그래도 없으면(1분에 한 번까지) 확장 코드 안의 버튼 표식으로요. 편집의 이름 칸에는 이렇게 찾은 이름이 흐리게 보여요.
  - 처음 켤 때 원래 확장이 이 브라우저에 남긴 설정(이름·화면에 두기·뺀 버튼·자동 담기)을 버튼 이름으로 맞춰 가져와요.
  - 가볍고 빠르게: 담긴 버튼마다 크기·자식 변화를 직접 지켜봐서, 보관함에서 연 창(제작실 같은 것)이 다음 프레임에 바로 보이고(전엔 최대 1.4초), 접히면 바로 숨어요. 펼침은 실제로 보이는 부분만 재서 숨은 패널 때문에 깜빡이지 않아요.
  - **바로 담기**(2.22.5): 다른 확장이 화면 맨 위층에 붙인 덩어리(와 그 섀도 루트) 안을 직접 지켜봐요(마리나라 화면 자체는 안 봐요). 전엔 맨 위층 요소 개수가 바뀔 때만 찾아서, 확장이 자기 덩어리 안에서 버튼을 새로 그리면 최대 15초 동안 화면에 떠 있었어요. 이제 이미 담았던 버튼은 다시 그려지는 그 순간(화면에 그리기 전)에 숨고, 처음 보는 버튼은 0.6초 떠 있으면(스쳐 가는 팝업은 거르려고, 전엔 1.2초) 바로 담겨요. 덩어리 안이 계속 바뀌는 확장(시계 같은 것)은 0.7초에 한 번만 살펴요. 15초마다 하는 전체 확인은 혹시 놓친 것만 잡아요. 확장 CSS·소스를 뒤지지 않아요. 끌어서 담기·끌어서 빼기는 빠졌어요(편집에서 해요).

- **롤플 장면 바를 위로**("Scene Bar Top" 기능): 롤플 아래의 장면 바(대화로 돌아가기·장면 끝내기·버리기·변환)가 채팅 위쪽 가운데의 작은 툴바 알약으로 올라가요. 돌아가기·끝내기·버리기는 Windows 11 알림창으로 한 번 묻고 실행해요(Enter = 실행, Esc = 취소). 변환은 마리나라가 직접 물어봐요.
- **입력창 + 메뉴**("퀵 팔레트" 기능): 입력창의 파일 첨부 버튼이 + 로 바뀌고, 누르면 Windows 11 메뉴가 위로 열려요.
  - 대사 따옴표 `""` / 나레이션 별표 `**`를 알아서 넣어요:
    - `"내용` 처럼 열려 있으면 닫아요 → `"내용"` (끝의 빈칸은 빼고 닫아요).
    - 닫혀 있으면 새 쌍을 넣고 커서를 가운데에 둬요. 앞 글자와 붙어 있으면 한 칸 띄워요: `"내용"` 에서 별표 → `"내용" *|*`.
    - 대사 안(`"내|용"`)에서 별표를 누르면 대사 뒤로 나가서 넣어요. 닫히지 않은 대사 안이면 먼저 닫아요: `"내용` → `"내용" *|*`.
    - 닫는 기호 바로 앞이면 새로 넣지 않고 그 뒤로 건너뛰어요.
    - 글을 고르고 누르면 감싸고(앞뒤 빈칸 제외), 이미 감싸져 있으면 벗겨요.
    - 입력창에 커서가 없으면 글 맨 끝에 넣어요.
  - 이미지 추가(마리나라 첨부 그대로), 턴 북마크 열기(그 확장이 켜져 있을 때만).
  - **문구 보관함**: 자주 쓰는 문구를 저장하고 검색·고정(★)·순서 바꾸기·수정·삭제(두 번 눌러 확인)·복사·입력창에 넣기. 처음 켤 때 퀵 팔레트가 이 브라우저에 남긴 메모를 한 번 가져와요.
  - 메뉴 아래쪽 "입력창 위에 버튼으로"에서 체크한 항목은 입력창 바로 위에 동그란 버튼으로 늘 떠 있어요. 체크해도 메뉴가 닫히지 않아서 여러 개를 한 번에 고를 수 있어요(휴대폰·태블릿 포함).
- 둘 다 꾸미기 → 채팅 꾸미기 → **채팅 도구**에서 켜고 꺼요. 원래 두 확장은 꺼 두세요(켜져 있으면 이쪽이 비켜요). 원래 확장과 달리 화면 전체를 지켜보거나 매 프레임 위치를 다시 재지 않아서 스트리밍 중에도 가벼워요.

- **집중 모드**(Ctrl + Alt + F, 보기 메뉴): 작업 표시줄·위젯·다른 창이 사라지고 채팅 창만 화면을 꽉 채워요. 위쪽 가운데의 흐린 알약 버튼이나 같은 단축키로 꺼요. 컴퓨터에서만 돼요.
- **글자 수**: 편집 화면의 입력칸에 쓰는 동안 칸 오른쪽 아래에 글자 수가 떠요.
- **저장 단축키**: 편집 화면에서 Ctrl + S 로 저장해요. 편집 화면이 없으면 브라우저 기본 동작 그대로예요.

## 알아 둘 점

- 원래 화면이 필요하면 Ctrl + Alt + D를 누르거나 시작 메뉴에서 **클래식 레이아웃**을 골라요. 오른쪽 아래 **데스크톱 모드** 버튼으로 돌아와요.
- 확장 저장 공간은 1MB예요. 배경화면·사진·아이콘 이미지는 자동으로 줄여서 저장하고, 가득 차면 알려 줘요.
- 밝은/어두운 모드는 마리나라 테마 설정을 따라가요.
- 확장을 끄면 추가한 요소, 스타일, 변수가 전부 사라져요.
- 확장 위젯은 내장 쪽이면 이 확장이 모은 버튼을, "확장 보관함 확장" 쪽이면 그 확장이 숨긴 버튼(`data-bgh-stored`)을 보여 줘요.
- 마리나라 화면 구조(`data-component`, `data-tour` 속성)와 크레딧 확장의 `#mac-credit-home`을 기준으로 동작해요. 마리나라나 그 확장이 업데이트되면 일부가 어긋날 수 있어요.
- 다른 스타일 확장이나 테마 CSS와 같이 켜면 서로 덮어쓸 수 있어요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | 확장 정보와 권한 (`full_page_access`). 스크립트는 `styles.js` → `desktop.js` 순서(`jsPaths`) |
| `desktop.js` | 창 관리자, 작업 표시줄, 시작 메뉴, 빠른 설정, 작은 앱(메모장·인터넷·YouTube), 북마크, 데스크톱 아이콘, 위젯·아이콘 꾸미기, 휴대폰 홈 화면 |
| `desktop.css` | 배경화면, 창 틀, 작업 표시줄, 아이콘 스타일, 팝업, 성능 옵션 |
| `theme.css` | 창 안쪽 색과 컨트롤 모양, 롤플 배경 제거 |
| `layout.css` | 창 안쪽 배치: 채팅 목록 툴바, 두 칸 설정, 캐릭터 아이콘 격자 |
| `home.css` | 홈 = 바탕화면, 유리 위젯, 내 위젯과 편집 모드 |
| `styles.js` | 예전 `apps.css`(대화·롤플·게임 앱, 입력창, 모델 선택창, 대사 색), `touch.css`(휴대폰·태블릿), 모바일 시트·토스트 CSS를 담은 스크립트. `desktop.js`가 다른 CSS 뒤에 `<style>`로 넣어요 |
| `dist/marinara-desktop.min.css` | 위 CSS 다섯 개를 합쳐 압축한 파일. manifest는 이것만 불러요. 직접 고치지 말고 `tools/build-css.py`로 만들어요 |
| `tools/build-css.py` | CSS 합치기·압축. 주석과 빈칸만 빼고 규칙은 그대로 둬요 |

마리나라는 확장의 CSS(manifest의 `cssPath` 파일을 합친 것)를 **256 KiB**까지만 받아요. 넘으면 가져올 때 `Validation Error`가 나요. 그래서 CSS가 커진 2.18부터 가져오기가 실패했고, 2.20.1부터는 마지막 두 스타일시트를 `styles.js` 안에 넣었어요(스크립트는 크기 제한이 없어요). `styles.js` 안의 CSS는 그냥 CSS로 고치면 되고, 백틱(`)과 `${`만 쓰면 안 돼요.

이제 manifest는 CSS 원본 대신 압축본 `dist/marinara-desktop.min.css` 하나만 불러요. 원본(약 239 KB)에서 주석과 빈칸을 빼면 약 180 KB라 80 KB쯤 여유가 생겨요. **CSS 파일을 고친 뒤에는 꼭 다시 만들어 주세요**(안 하면 고친 게 반영되지 않아요):

```bash
python3 tools/build-css.py
```

`python3 tools/build-css.py --check`는 압축본이 원본과 다르거나 256 KiB를 넘으면 실패해요.

### 화면 검수판

바꾼 화면을 실제 CSS로 그려서 밝은·어두운 테마 × 컴퓨터·휴대폰 스크린샷을 한 번에 찍어요(Storybook처럼). 마리나라 쪽 화면(채팅 설정 시트, 로어북·프리셋 줄)은 마리나라 소스의 클래스 구조를 본뜬 가짜 화면이에요. 토스트는 `desktop.js`의 진짜 `toast()`를 돌려요.

```bash
node tools/shots.mjs
```

아이콘은 스타일 12종을 한 줄씩 찍어요. 결과는 `tools/gallery/shots/index.html`에서 한눈에 봐요(저장소에는 안 올라가요). 화면 하나만 보려면 `node tools/shots.mjs toasts`처럼 이름 일부를 붙여요. 화면 구조를 바꾸면 `tools/gallery/stories.html`도 같이 고쳐 주세요.
